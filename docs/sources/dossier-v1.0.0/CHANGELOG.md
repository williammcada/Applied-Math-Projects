# Changelog

## Dossier v1.0.0 — September 15, 2026

Initial proposed build baseline for five independent, self-contained HTML projects: Road Trip Planner, Food Truck, Theme Park Designer, Mars Colony, and Powers of Ten.

Defines 50 core learning objectives, required evidence/representation contracts, project-specific screen flows, canonical classroom datasets, narrative and visual directions, artwork registers, performance-ending rules, print/export requirements, source provenance, and release acceptance tests.

Adapts the objective/claim/representation, validation, stable-ID, and version-governance lessons from TestForge and AAC without importing their quotas or building a generator.

Corrects early brainstorming traps: fuel on a fixed route versus a per-day cost; travel days versus hotel nights; an algebraic intercept versus literal day-zero expenditure; unsold food costs; path-area double-counting; stocks versus rates; scale-ratio direction; and the distinction between mathematical possibility and practical model size.

Includes 77 passing reference checks. Document rendered and all 44 pages visually reviewed. No playable application, physical device, school network, or classroom timing is claimed tested in this dossier release.

Next revisions should preserve accepted scope and stable IDs, record actual changes, and distinguish app, content, and progress-schema versions.
