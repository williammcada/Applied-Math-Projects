## 1. Purpose and audience

A family of five interactive applied-mathematics projects: Road Trip Planner, Food Truck / Business Launch, Theme Park Designer, Mars Colony, and Powers of Ten / Scale of Reality.

**Primary audience / operator:** Students completing interactive applied-math project work under teacher supervision.

## 2. Standards selection

**Universal baseline:** U-01 through U-08 where applicable.

**Conditional modules:** S-02 Curriculum/Assessment/Evidence; S-04 Distribution/Deployment; S-05 Applied Mathematics Project Series

Apply only the selected modules and project-local requirements. Do not import restrictions from unrelated projects.

## 3. Project-specific requirements

- Connect each learning objective to a student action, representation, and observable evidence.
- Distinguish mathematically invalid work from mathematically valid but strategically weak design.
- Include appropriate visual material, contextual help, field validation, and coherent narrative where specified.
- Preserve each project's own mathematical identity and scope.
- Music is not required for this family, but that is not a universal ban.
- Do not let one project's duration, representations, or decision rules automatically become requirements for the others.

## 4. Preserve from the current accepted project

- Five-project family identity.
- Road Trip Planner.
- Food Truck / Business Launch.
- Theme Park Designer.
- Mars Colony.
- Powers of Ten / Scale of Reality.

## 5. Relationship to other projects

- Shares universal educational/assessment principles but remains distinct from TestForge, MathQuest, and other games.
- May reuse common code later if deliberately designed, but the repository structure does not itself create a shared engine.

A conceptual relationship is not proof of an implemented integration. Do not invent a shared API, data schema, identity layer, or deployment dependency without an explicit integration task.
