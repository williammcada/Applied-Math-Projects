# Powers of Ten — Asset manifest

App 0.1.0 · A WILLIAM MCADA PRODUCT

All artwork is original code-authored SVG embedded in the HTML. No photographs, microscopy, stock art, downloaded fonts or third-party image files are included. Scientific data citations support teaching values, not image provenance. No external artwork license is needed for these original drawings; this document does not grant a new license to the repository.

Dimensions below are SVG viewBox units unless specified as physical print dimensions. Meaningful diagrams use `role="img"` and text alternatives; adjacent tables/prompts provide numerical equivalents. Responsive previews are never physical rulers.
