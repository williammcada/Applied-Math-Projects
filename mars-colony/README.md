# Mars Colony · Red Horizon v0.1.0

**A WILLIAM MCADA PRODUCT**

[Open Mars Colony](https://mcada-applied-math.netlify.app/mars-colony/) · [Download standalone HTML](MarsColony_v0.1.0.html) · [Finalized specification](../docs/change-specs/MARS-COLONY-v0.1.0.md) · [Teacher guide](docs/TEACHER-GUIDE.md)

Three estimated 45-minute lessons for advanced Grade 5/pre-algebra. Pairs plan a 24-person research outpost, calculate resources, choose modules, model stocks, test a three-day reduction in solar output and defend a resilient design. Ten dossier objectives are retained; all engineering quantities are explicitly fictional.

Start a mission with a pair alias. Use Check & continue, revise freely, and export a JSON backup. Import adds new copies. Saved missions belong to this browser/origin; QR codes do not synchronize students. Individual and all-Mars deletion include confirmation and backup guidance.

`src/` holds source; run `python build.py` to generate byte-identical hosted and standalone HTML. Core runtime has no external dependencies. Netlify publishes the repository root with no build command. Tests use Node and Playwright; browser checks are emulation, not physical iPad acceptance.
