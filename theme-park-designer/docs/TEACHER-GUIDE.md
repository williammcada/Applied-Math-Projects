# Theme Park Designer — Teacher Guide

**Version 0.1.0 · A WILLIAM MCADA PRODUCT**

Use pairs with alternating Planner and Checker roles. The proposed pacing is four 45-minute lessons; adjust to the learners. Pair completion provides evidence of supported design work. Separate transfer responses provide additional individual evidence, with assistance recorded. Neither the ending nor corrected arithmetic is an automatic mastery score.

## Before class

Open the application on the classroom network and actual iPad/browser. In **Teacher**, run diagnostics. Create a practice design, export it, and import the file through **Saved work**. Print a scale map at 100% and measure the 5 cm calibration line. These physical classroom checks are still pending in the release record.

Use aliases rather than student names. Save an exported backup at each lesson boundary; browser storage can be cleared or unavailable. The desktop HTML includes all assets and can run offline. Hosted offline reopening is outside the guarantee.

## Lesson sequence

| Lesson | Stages | Main evidence |
| --- | --- | --- |
| 1 | Brief; scale and site | 1 cm:4 m, unit-free 1:400, 15 × 10 cm drawing, 2,400 m² site, linear versus area change |
| 2 | Facility mathematics; layout | Six footprints, circle/triangle inside footprints, 90° rotation, bounds and overlap; swap roles |
| 3 | Paths and landscape; budget | Union, connected entrances, allocation fractions/percentages, full boundary quote, signed balance; export backup |
| 4 | Inspection and revision; individual transfer | Distinct inspected Plan A/B, one numerical tradeoff, recommendation, separate transfer A/B, report |

The application offers automatic role-swap reminders after selected checkpoints and a manual swap control. Inspectors distinguish impossible placement from a mathematically correct but weak design. Let learners inspect and revise a correctly calculated design that has too little green space, disconnected access, excessive paths, or an overspend.

Use π = 3.14. All lengths below are real-world meters unless drawing units are stated. The baseline is one valid example, not the only solution.

## Interpret the five statuses

| Status | Meaning |
| --- | --- |
| Draft | Required evidence is absent, stale, or incomplete. |
| Provisional | A required checkpoint was bypassed with a teacher reason. |
| Return to the design table | Completed current arithmetic describes a design failing one or more approval constraints. |
| Park approved | Six facilities, valid geometry, rooted access, paths within 240–600 m², green at least 480 m², and cost at most 90,000 cr. |
| Opening-day distinction | Approved, plus at least 4,500 cr reserve and a designated empty rectangular expansion zone of at least 100 m². |

Two required main spines reserve 384 m², so the 240 m² minimum cannot fail through ordinary v0.1.0 path editing. The 600 m² upper limit can fail. Door access requires positive-length edge contact with the entrance-rooted four-neighbor path network; touching only a corner does not count.

Save inspected Plan A before editing. Plan B must change geometry or land designation, not just its name. An equal-cost alternative is allowed if the numerical comparison and reasoning are meaningful. Learners can recommend either snapshot. The report uses the selected frozen snapshot, even if the current working plan differs.

Read the tradeoff reflection yourself. A nonempty response is recorded, not graded for quality. Teacher review is separately labeled. First checked responses, current responses, number of attempts, and support records should inform discussion rather than become an unqualified score.

## Individual transfer

The two learners answer separate variants. Initial digital responses are covered until both have been recorded. This reduces casual copying; it is not secure assessment. Teacher mode and public source expose the answer logic.

| Variant | Drawing dimensions | Real area | Site percentage | Drawing dimensions after rotation |
| --- | --- | --- | --- | --- |
| A: 12 × 8 m rectangle | 3 × 2 cm | 96 m² | 4% | 2 × 3 cm |
| B: 16 × 6 m rectangle | 4 × 1.5 cm | 96 m² | 4% | 1.5 × 4 cm |

Paper or oral alternatives require a teacher note in the Teacher workspace. Calculator use during transfer is a separate recorded support setting. A bypass needs a reason and preserves a provisional final status; it cannot make impossible geometry valid.

## Saving, deletion, and printing

Use **Export progress** for the active session and **Export backup** for saved sessions. Imports validate versions and values before showing a review; committing an import makes a new session. Use the same browser/origin to resume local work. If saving is denied, export the in-memory work before closing the page.

Deleting a snapshot can invalidate the comparison or recommendation that uses it. Deleting a session removes its related plans and evidence. **Clear all** affects Theme Park sessions only. Each destructive action offers Cancel and backup export. Recovery after confirmed deletion requires a prior backup.

The student report, map, brochure, transfer slips, and teacher answer reference are separate outputs. The answer reference dynamically follows the selected report plan, or the working plan when none is selected; its first page also shows the fixed baseline. Choose A4/Letter and 100% scale. The site must measure 150 × 100 mm, each cell 5 mm, and the calibration line 50 mm. Browser/printer scaling must be measured on paper.
