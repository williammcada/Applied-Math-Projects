# Road Trip Planner

**A WILLIAM MCADA PRODUCT**

Interactive applied-math project centered on planning a road trip, constructing a linear cost model, evaluating affordability, and revising a plan after a hotel-price change.

This subproject belongs to the **Applied Mathematics Project Series** repository.
