# Road Trip Planner asset manifest

App 0.1.0 / Content 1.0.0. All narrative illustrations are original SVG artwork authored for this implementation in `src/art.js`, embedded into both HTML entry points. No external assets, fonts, raster downloads or licensing dependencies are used. The preserved dossier concept art remains unchanged in the source archive.
